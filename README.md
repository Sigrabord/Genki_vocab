# genki.voc — лексика Genki, 3-е издание

Личное приложение для заучивания слов уроков 1–23 (1103 слова): карточки, тест, письмо (кана или ромадзи), аудирование, свои слова. Работает офлайн, прогресс хранится в браузере.

## Как выложить (GitHub Pages)
1. Создайте новый репозиторий и загрузите в него **содержимое** этой папки (файл `index.html` должен лежать в корне).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
4. На телефоне: «Добавить на экран «Домой»» — получится приложение.

## Где что лежит
- `textbook/genki.json` — словарь. Поля слова: `j` (кандзи, может быть пустым), `k` (чтение), `ru`, `en`, `c` (тип: `n` существительное, `r` глагол на -ru, `u` глагол на -u, `x` неправильный глагол, `ai` い-прилагательное, `an` な-прилагательное, `o` прочее).
- `js/store.js` — расписание повторений и сохранение прогресса. `js/kana.js` — проверка ответов. `js/main.js` — интерфейс.
- После правки файлов измените `VERSION` в `sw.js`, иначе телефон покажет старую версию из кэша.

## Заметки
- Слово считается выученным, когда интервал повторения достиг 5 дней.
- Перенос прогресса между устройствами: «Мои слова» → «Скачать копию» / «Загрузить копию».
- Словарь взят с learnjapaneseaz.com и подправлен (исправлены чтение 下手, 売る и типы глаголов 覚える, 出る, 始まる). Только для личного использования.
